# விளம்பர செயலி

பல படங்களை ஒருங்கிணைத்து உருவாக்கப்பட்ட ஒரு அழகான விளம்பர (Advertisement) முகப்புத் திரை.

## அம்சங்கள்
- முதன்மை விளம்பரப் படம் (Featured Image).
- பல சிறிய படங்களின் தொகுப்பு (Image Collage).
- Responsive Design (மொபைல் மற்றும் டெஸ்க்டாப் இரண்டிலும் அழகாக தோன்றும்).
- 'Shop Now' என்ற அழைப்பு பட்டன் (Call to Action Button).

## எப்படி தொடங்குவது
1. `flutter pub get`
2. `flutter run`
